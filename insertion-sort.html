Insertion sort is the first algorithm CLRS presents in Introduction to Algorithms (chapter 2.1). The book compares it to sorting a hand of playing cards: the cards already in your hand are in order, you pick up the next one from the table, and you slide it in from the right until it sits in the right place.

On an array, the left part is the sorted hand. Each round takes the next element (the key), shifts every larger element in the sorted part one slot to the right, and drops the key into the gap.

CLRS proves it correct with a loop invariant: before each round, the elements to the left of the key are the original ones, already in sorted order. The invariant holds at the start, each round keeps it true, and when the loop ends it says the whole array is sorted.

On sorted input each key needs one comparison, so the time is linear. On reverse-sorted input each key moves all the way to the front, so the time is quadratic. The average case is quadratic as well. 

insertion_sort(A):
    for j = 1 to length(A) - 1:
        key = A[j]
        i = j - 1
        while i >= 0 and A[i] > key:
            A[i + 1] = A[i]       # shift right
            i = i - 1
        A[i + 1] = key            # insert
